柔性传感器 · 信号分析

把指尖敲击变成字母

一块可拉伸的电阻传感器,会记录你按得有多重、按了多久。用摩尔斯电码敲击它,一个小程序就能读出你敲的字母——26 个字母26 个全部认对,连过去被认为"单独无法判读"的纯点 / 纯划字母也全部拿下。这个页面讲清楚它怎么做到的。

  • 26  个字母
  • 约 4,800  次敲击判读
  • Keysight 34461A  万用表,约 2.4 Hz

原始数据

传感器到底给了我们什么

每一份录制,都是一个字母在传感器上连续敲几十~上百次。每按一下,柔软的材料被挤压,它的电阻就往上跳一下;松手回落。万用表大约每秒记录两次。

整段原始信号就是一条按压时上升的波动曲线,没有任何标注——程序必须自己找出每次敲击,再判断出规律。

方法 · 四个步骤

程序怎么读出一个字母

  1. 1

    找出每一次敲击

    先减掉缓慢漂移的静息基线,曲线上每个明显的鼓包 = 一次手指按压。

  2. 2

    量每次敲击的大小

    量它的峰高(电阻跳了多高,ΔR/R₀)和时长(按住了多久)。

  3. 3

    小敲 = 点,大敲 = 划

    把敲击分成"小"和"大"。"大"可能是按得更高,也可能是按得更久——这两条线索都用上(见下一节)。

  4. 4

    查摩尔斯码表

    点划序列(如 —··)对照标准码表 → 字母 D。

同一条规则,两种情况

怎么判断"大"——不能用固定数值

一次敲击看起来有多大,取决于传感器的软硬和这个人按得多重。所以程序不用固定数值,而是靠比较。分两种情况:

① 混合字母(含点又含划)

像 D、F、G——同一份录制里,划就是比点高。直接在这份录制内部按峰高相对比较即可。

58% 全局固定分界 → 约 95%+ 同一录制内相对比较
② 纯字母(全点或全划)

像 E、S、I、M——一份录制里没有高矮对比。但划按得更久(点 ≈ 3s、划 ≈ 4s)。关键是:时长是人为动作,跨录制稳定,而峰高会乱。

按时长兜底 · 分界 ≈ 3.6s

每个字母的条形 = 该字母每次重复被完整解码正确的比例;末尾 ✓ 是多数投票认对。26 个字母全部认对。其中 7 个纯点 / 纯划字母(绿松石色)靠时长判定。

这意味着什么 · 大白话

怎么看这个结果

  • 传感器能干净地分辨"轻/重"和"短/长"敲击。 这是核心能力。只要敲击被清晰采集,点/划判读近乎完美——约 4,800 次里错不到 0.4%。
  • 纯字母也能认出来——靠"时长"。 全点或全划的字母(E、T、I、M、O、S、H),过去以为单独一个无法判读。这次靠"划按得更久"把 7 个纯字母全部认对。因为按压时长是人的动作,不随传感器状态漂移。
  • 关键坑:挨得近的按压别被并成一团。 起初 C、X 认不出,是因为峰检测把一个字母里挨得很近的几次按压吞并成一个大团,短波(点)被吃掉了。改成"先找峰、再按峰间的凹陷分开"后,短波全部现形,C、X 也认对了。

方法：敲击检测(先做滚动基线去趋势,消除慢漂移)→ 有高矮对比就按相对峰高判、没有对比就按绝对时长(≈3.6s)兜底 → 点/划 → 查摩尔斯码表。一份失败录制(传感器开路)已剔除。

数据：36 份"电阻—时间"录制,每字母一份,Keysight 34461A。传感器概念参考 Wei 等,明胶稳定液态金属导电水凝胶。
