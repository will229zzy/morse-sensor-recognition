# 三方法对比实验(摩尔斯字母识别)

在**完全相同的数据与划分**上对比三种决策方式,回答一个问题:
**这个任务的信息量在"物理特征"里,还是在"模型深度"里?**

## 三种方法(共用同一个物理前端)

所有方法的输入都来自同一条流水线:去毛刺 → 去慢漂移(ΔR/R₀) → 峰检测(`find_peaks` +
prominence,取半高宽 FWHM)。**只有"决策环节"不同**,所以对比是受控的。

| | 方法 | 输入表示 | 需要训练数据 | 核心思想 |
|---|---|---|---|---|
| ① | **规则解码** | 组内相对峰高 / 半高宽 | **0** | 人显式写出"组内相对比较" |
| ② | **手工特征 + 随机森林**(另附 SVM) | 21 维定长特征 | 少 | 人给特征,机器学决策边界 |
| ③ | **Transformer encoder**(另附 BiLSTM) | 按压 token 序列 | 多 | 机器自己学"元素之间的关系" |
| (消融) | **1D-CNN,原始波形** | 定长重采样波形(128 点) | 多 | 不用物理前端,端到端 |

### 为什么 ③ 选 Transformer 而不是 CNN
本方法的核心物理发现是:**点/划是相对的**——要跟同一个字母内的邻居比,不是看绝对值。
**self-attention 做的正是"元素之间互相比较"**,所以它的归纳偏置与该物理规律天然对应:
我们用规则显式写下的东西,注意力机制隐式学了出来。

此外,字母时长跨 ~2 s 到 ~60 s,**固定窗口 CNN 必须重采样,会把"按压持续多久"这个绝对
信息归一化掉**,而 E(·) 与 T(—) 恰好只靠时长区分。序列表示(每次按压一个 token)天然变长,
不存在这个问题。消融那一路保留固定窗口,用来量化这个短板。

## 样本与标签

- 一个样本 = **一次完整的字母敲击**(one repetition)。
- 共 **2530** 个样本、**26** 个字母、**34** 份录制。
- 排除:`K-30`(接触故障)、`D13+F58`(两字母混合录制)。

## 划分协议(严格,防泄漏)

1. **5 折交叉验证**,每个样本恰好被测试一次 → 三种方法都得到覆盖全部 2530 个样本的混淆矩阵。
2. 折 = 每份录制内**按时间顺序**切的 5 个**连续块**(不是随机打散)。
   随机打散会让相邻的两次按压一个进训练、一个进测试,传感器状态几乎相同 → 泄漏。
3. 测试块**边界两侧各清除 1 个重复**(purged CV),进一步切断相邻样本的相关性。
4. 需要训练的方法:另取一折做**验证集**用于早停,其余 3 折训练。规则解码不训练。

> 这套协议是刻意做严的。上一篇论文里"第 1 个 epoch 验证准确率就 1.0000、用 10% 训练数据
> 也是 1.0000"的现象,通常就是划分过松(窗口重叠/随机打散)的信号,容易被审稿人追问。

## 指标

与上一篇论文同一套:accuracy、macro / weighted 的 precision·recall·F1、Cohen's κ、
per-class AUC、micro-average AP。

## 运行

```bash
cd analysis/ml
python dataset.py      # 建统一数据集 → ../out/ml/dataset.npz
python benchmark.py    # 三方法 5 折对比 → ../out/ml/results.npz + *.csv
python figures.py      # 全套结果图 → ../out/ml/figures/ + ../out/ml/origin/
```

## 输出

- `out/ml/figures/` —— 混淆矩阵(每方法一张)、model comparison、feature importance、
  learning curve(准确率 vs 训练集大小)、训练曲线(epoch)、逐字母准确率、PR 曲线、ROC 曲线、
  t-SNE(2D/3D,原始波形空间 vs 物理特征空间)。图内文字为英文,投稿可直接用。
- `out/ml/origin/` —— 每张图对应的 CSV,可在 Origin 里自行重画。
- `out/ml/summary_metrics.csv` / `fold_metrics.csv` —— 汇总与逐折指标。
