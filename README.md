# 指尖摩尔斯电码字母识别

用一块**可拉伸的电阻传感器**输入摩尔斯电码:在传感器上按压——轻敲=点(·)、重敲=划(—)——
一个小程序从电阻信号里读出你敲的是哪个字母。本仓库是这批原始数据的分析、识别程序和可视化报告。

传感器概念参考 Wei 等《Gelatin-stabilized liquid metal for conductive hydrogels…》(明胶稳定液态金属导电水凝胶)。

---

## 数据是什么

- 每个字母一份 `.csv`,是 **Keysight 34461A 万用表**记录的「电阻(Ω)—时间」曲线,采样约 2.4 Hz。
- 每份录制里,该字母的摩尔斯码被**重复按压几十~上百次**(文件名数字后缀 = 重复次数,如 `F42`=按 42 次;无后缀默认约 100 次)。
- 每按一下,材料被挤压,电阻上跳;松手回落。原始信号就是一条按压时上升的波动曲线,**没有任何标注**。

## 方法(四步)

1. **找敲击** —— 先做**滚动基线去趋势**消除慢漂移,曲线上每个明显鼓包 = 一次按压。
2. **量大小** —— 每次敲击量两项:**峰高** `ΔR/R₀`(跳多高)和**时长**(按多久)。
3. **小=点,大=划** —— "大"可能是更高,也可能是更久;分界**对每份录制单独设定**。
4. **查摩尔斯表** —— 点划序列(如 `—··`)对照标准码表 → 字母(`D`)。

### 关键发现:同一条规则,两种情况

峰高的绝对值被传感器批次和按力主导——**一块传感器上的点,可能比另一块上的划还高**,固定阈值只有 58%。所以靠**比较**,分两种情况:

| 情况 | 判据 | 点/划正确率 |
|---|---|---|
| **混合字母**(含点又含划,如 D/F/G) | 同一录制内**相对峰高** | 约 95%+(固定阈值仅 58%) |
| **纯字母**(全点或全划,如 E/S/I/M) | **绝对时长**(点≈3s、划≈4s,分界≈3.6s) | — |

纯字母一份录制里没有高矮对比,但**划按得更久**;而按压时长是人为动作,**跨录制稳定**,峰高会乱。这一招把 7 个纯字母全部救回。

## 识别结果

| 指标 | 数值 |
|---|---|
| 点/划判读(约 4,800 次敲击) | **97.9%** |
| 整字母解码(每次重复) | **97.0%** |
| 字母认对(多数投票) | **23 / 26**(含全部 7 个纯字母) |

- 仅 **C / X / Y** 未认出——那三份录制本身**点划没做出区分**(点按太重 / 划按太短),重录即可,不是方法问题。
- 早期版本(仅相对峰高、无去趋势)为整字母 90.2%、纯字母无法判;加入**滚动去趋势 + 时长兜底**后提升到上表。

## 目录结构

```
raw data/                每个字母一份「电阻—时间」CSV(原始数据)
analysis/
  morse_pipeline.py      加载 / 去毛刺 / 滚动去趋势 / 敲击检测 / 重复分组（核心库）
  recognize_all.py       混合规则识别器(峰高 or 时长)+ 全 A–Z 结果
  evaluate_final.py      最终指标汇总,输出 out/final.json
  classify.py            逐文件 Otsu 二分(峰高)工具函数
  recognize.py           识别单个文件(命令行 demo)
  amp_study.py           证明「绝对峰高分不开点/划」
  feature_test.py        比较峰高/峰宽/面积哪个全局判据最好(结论:峰宽)
  example_fig.py         峰高示例图(D / F)
  duration_fig.py        时长示例图(纯字母 I / M)
  report.src.html        可视化报告模板
  report.html            最终可视化报告(注入图片与数据后)
  out/                   图表与中间结果(final.json 等)
```

## 复现

```bash
cd analysis
python3 recognize_all.py      # 全 A–Z 识别结果表(混合规则)
python3 evaluate_final.py     # 最终指标:23/26、点划 97.9%、整字母 97.0%
python3 recognize.py "../raw data/D-20 2026-08-19 13-50-36 0.csv"   # 识别单个文件
```

## 数据质量说明

- `K-30`:传感器在录制中途开路(电阻跳到 23 MΩ),整份剔除,字母 K 用 `K70`。
- `B-64` 尾段等:存在长时间漂移鼓包(非按压),会被宽度否决。
- `D13+F58`:一份文件里混了 13 次 D + 58 次 F。
