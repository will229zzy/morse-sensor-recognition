# 指尖摩尔斯电码字母识别

用一块**可拉伸的电阻传感器**输入摩尔斯电码:在传感器上按压——轻敲=点(·)、重敲=划(—)——
一个小程序从电阻信号里读出你敲的是哪个字母。本仓库是这批原始数据的分析、识别程序和可视化报告。

传感器概念参考 Wei 等《Gelatin-stabilized liquid metal for conductive hydrogels…》(明胶稳定液态金属导电水凝胶)。

---

## 数据是什么

- 每个字母一份 `.csv`,是 **Keysight 34461A 万用表**记录的「电阻(Ω)—时间」曲线,采样约 2.4 Hz。
- 每份录制里,该字母的摩尔斯码被**重复按压几十~上百次**(文件名数字后缀 = 重复次数,如 `F42`=按 42 次;无后缀默认约 100 次)。
- 每按一下,材料被挤压,电阻上跳;松手回落。原始信号就是一条按压时上升的波动曲线,**没有任何标注**。

## 方法(四步)

1. **找敲击** —— 曲线上每个明显高出静息的鼓包 = 一次按压。
2. **量峰高** —— 每次敲击电阻跳了多高,记为相对静息的百分比 `ΔR/R₀`。
3. **小=点,大=划** —— 把敲击按大小二分;分界线**对每份录制单独设定**(Otsu)。
4. **查摩尔斯表** —— 点划序列(如 `—··`)对照标准码表 → 字母(`D`)。

### 关键发现:点/划是「相对」的,不是固定阈值

峰高的绝对值被传感器批次和按力主导——**一块传感器上的点,可能比另一块上的划还高**。

| 判别方式 | 点/划正确率 |
|---|---|
| 全局单一固定阈值 | **58%**(约等于瞎猜) |
| 在同一份录制内部相对比较 | **约 95%** |

这和真实摩尔斯一致:划被定义为「比周围的点更长」,靠比较,而非固定长度。

## 识别结果

| 指标 | 数值 | 说明 |
|---|---|---|
| 点/划判读 | **94.9%** | 同时含点和划的字母 |
| 整字母解码 | **90.2%** | 切分干净的重复上 |
| 单一形态字母 | 约 50% | E T I M O S H — 单看一个字母无法判,需上下文 |

- 分段正确的重复里,点/划分类**多数字母达 100%**(A/F/J/Q/U/X 等)。
- 主要瓶颈是**分段**(长录制里电阻缓慢漂移,难以把一次重复干净切开),属可解决的信号处理问题。

## 目录结构

```
raw data/                每个字母一份「电阻—时间」CSV(原始数据)
analysis/
  morse_pipeline.py      加载 / 去毛刺 / 基线校正 / 敲击检测 / 重复分组（核心库）
  classify.py            逐文件 Otsu 二分 → 点/划 → 解码
  evaluate.py            汇总识别率,输出 out/evaluate.json
  recognize.py           识别单个文件(命令行 demo)
  amp_study.py           证明「绝对峰高分不开点/划」的分析
  example_fig.py         生成标注示例图
  report.src.html        可视化报告模板
  report.html            最终可视化报告(注入图片与数据后)
  out/                   图表与中间结果
```

## 复现

```bash
cd analysis
python3 morse_pipeline.py     # 质检表:每文件重复数 / 每重复元素数
python3 evaluate.py           # 识别率汇总
python3 recognize.py "../raw data/D-20 2026-08-19 13-50-36 0.csv"   # 识别单个文件
```

## 数据质量说明

- `K-30`:传感器在录制中途开路(电阻跳到 23 MΩ),整份剔除,字母 K 用 `K70`。
- `B-64` 尾段等:存在长时间漂移鼓包(非按压),会被宽度否决。
- `D13+F58`:一份文件里混了 13 次 D + 58 次 F。
